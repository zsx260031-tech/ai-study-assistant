# 智学助手 · AI Study Assistant

一个把大模型接入真实学习场景的 Web 应用：输入任何计算机概念，AI 返回结构化讲解——一句话定义、生活类比、最小可运行示例、常见误区，以及三道自测题。

## 为什么做它

学计算机时最费时间的不是写代码，而是「概念第一次没弄懂，后面全卡住」。教科书讲得太抽象，搜索引擎给的是碎片，聊天机器人给的是一大段散文。这个项目把讲解压缩成固定的五块结构，直接对上复习时的需求：知道定义、能类比、能跑代码、避开坑、能自测。

## 功能

- 概念讲解：定义 / 类比 / 示例代码 / 误区 / 自测题，一次生成
- 多语言示例：Python、C++、JavaScript
- 结构化输出：通过 JSON 模式约束模型输出，前端按字段渲染，而不是整段文字
- 学习记录：每次生成自动存入 SQLite，点击历史即可回看
- 自测题答案可折叠，先自己做再对答案

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.14 + Flask 3.1 |
| 模型 | DeepSeek Chat Completions API（`deepseek-chat`，JSON 输出模式） |
| 存储 | SQLite（标准库 sqlite3） |
| 前端 | 原生 HTML / CSS / JavaScript，`fetch` 调用后端接口 |

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 页面 |
| POST | `/api/generate` | 生成讲解，body：`{"concept": "...", "language": "python"}` |
| GET | `/api/history` | 最近 12 条学习记录 |
| GET | `/api/record/<id>` | 单条记录详情 |

## 运行

```bash
pip install -r requirements.txt
set DEEPSEEK_API_KEY=你的密钥
python app.py
```

浏览器打开 `http://127.0.0.1:5000`。

## 设计要点

- **Prompt 约束结构**：系统提示词里写死了 JSON schema，并把 `response_format` 设为 `json_object`，模型返回后直接 `json.loads`，省去解析自然语言
- **失败重试**：网络错误或限流时自动重试一次，仍失败则把错误原样返回给前端
- **输出兜底**：模型偶尔少字段，`normalize()` 统一补默认值，前端不会因为缺字段白屏
- **入库不存原始回复**：只存清洗后的结构，历史记录稳定可回放

## 已知限制

- 单机原型，没有用户系统，端口固定 5000
- 每次生成消耗一次 API 调用，未做缓存
- 依赖外部模型服务，断网时不可用
